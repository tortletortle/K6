## 【7】配置引脚功能。

回到 **Pinout**** ****&**** ****Configuration**** **界面,点击“**RCC**** ****Mode**** ****and**** ****Configuration**”功能框右上角的**小三角形**可以进行窗体的展开与收起。按住鼠标右键不放,可以拖动右侧芯片引脚俯视图的位置,鼠标滚轮,可以对其进行放缩。

## 这是 STM32CubeMX 的图形化配置核心工作,针对项目中不同的应用需求和硬件设计,为需要的引脚指定相应的功能,为涉及到的外设配置合适的参数。

![](基于STM32CubeMX与HAL库的嵌入式开发快速入门.assets/img_0011.jpg)

本教程的项目案例中,LED2 灯引脚接到了芯片的 **PB8**** **上。所以,需要将 **PB8**** **引脚设置为 **GPIO 输出**功能。

首先,用鼠标单击芯片引脚视图中的 **PB8**** 引脚**,然后,在其复用功能的下拉列表中,选择该引脚的“**GPIO\_Output**”功能,设置成 **GPIO**** 输出**方式。

![](基于STM32CubeMX与HAL库的嵌入式开发快速入门.assets/img_0012.jpg)

引脚功能确定后,STM32CubeMX 自动展开功能参数配置界面,**设置初始化默认参数**。在 “**System**** ****Core**”菜单项中的“**GPIO**”,在其右边展开的“**Configuration**”参数配置框中,选择“**GPIO**”选择卡,里面可能有多个引脚,鼠标先点击需设置的引脚,再对其进行初始化参数配置。本教程中,选择的是 **PB8 **引脚。

![](基于STM32CubeMX与HAL库的嵌入式开发快速入门.assets/img_0013.jpg)

鼠标选中 **PB8**** **引脚后,选中条目背景呈灰色,在下方出现该引脚的初始化参数,部分选择已设置默认参数,可根据项目实际需求进行设置和修改。

在本项目案例中,LED 灯为低电平点亮,因此,在“**PB8**** ****Configuration**”参数框中,将“**GPIO**** ****output**** ****level**”设置成“**High**”,其他参数保持默认即可。也就是在系统上电后, PB8 引脚的初始化输出电平为高电平,LED2 灯熄灭。

被修改过的引脚,其右侧的“**Modified**”选项框会被勾选,作为标记。

![](基于STM32CubeMX与HAL库的嵌入式开发快速入门.assets/img_0014.jpg)

完成功能选择的引脚上会标志一个**图钉**,并会根据不同功能填充不同的颜色,同时在该引脚旁边标识出所选定的功能。

![](基于STM32CubeMX与HAL库的嵌入式开发快速入门.assets/img_0015.jpg)

**【11****】最好在保护区内编写用户程序。**

在基于 STM32CubeMX 图形配置软件生成的工程中,编写用户业务逻辑程序时,最好将代码放在“**/\*USER CODE BEGIN ...\*/**”和“**/\*USER CODE END...\*/**”之间。这是一个**代码保护区**,当你需要在 STM32CubeMX 再次配置或者修改本工程而重新生成新的程序框架工程时,**代码保护区内已经写好的程序,将被保留下来**,也就是说,可以在前面已做的工作和已写

的程序上,继续开发;而在代码保护区以外的程序会被清除掉。

![](基于STM32CubeMX与HAL库的嵌入式开发快速入门.assets/img_0026.jpg)
